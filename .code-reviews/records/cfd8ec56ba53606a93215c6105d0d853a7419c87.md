## Summary

Adds `.github/workflows/code-review-pr.yml`: a PR-triggered GitHub Actions
workflow that reads `.code-reviews/ledger.jsonl`, averages per-commit review
scores for the commits in the PR (skipping the hook's own
`chore(code-review):` follow-ups), and posts/updates a single summary comment
on the PR. Fork PRs are skipped (their token can't comment).

against the general criteria (correctness, security, consistency,
maintainability) with a GitHub Actions / shell / jq lens.

session. `api/` additionally adds the hook's working-file ignore to
`.gitignore`, which `web/` and `admin/` already carry. No API-contract
